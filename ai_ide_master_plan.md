## System Objective & Architecture

You are an autonomous AI coding agent tasked with upgrading our fork of [ibarrajo/ApplyPilot](https://github.com/ibarrajo/ApplyPilot) into a **Dual-Track, Self-Evolving Job Acquisition System & MCP Server**:

1. **Part 1 — Daily Omni-Channel Discovery (`social_discovery/` + `career_resolver/`):**
   - Scrapes fresh hiring posts daily from **Reddit** (`.json` feeds), **LinkedIn Posts**, **X (Twitter)**, and **Threads** (via time-filtered search engine dorks — **NEVER** use logged-in LinkedIn/X session cookies).
   - Monitors **Official Company Career Sites** ([Greenhouse Job Board API](https://www.greenhouse.com/api), [Lever Postings API](https://github.com/lever/postings-api), Ashby, Workday, and a custom company watchlist) plus [JobsPipe MCP](https://jobspipe.dev/mcp-server) / [JobSpy](https://github.com/speedyapply/JobSpy).
   - Uses a **Zero-Token Regex & Entity Classifier** to extract published HR/founder emails and ATS links, and uses a **Career Site Resolver** to find the official `/careers` portal when a post only mentions a company name.
   - Classifies every opportunity into one of three execution routes: `EMAIL_ONLY`, `PORTAL_ONLY`, or `DUAL_ATTACK` (both portal application and direct HR email).

2. **Part 2 — Dual-Track Execution + Shared Email HITL + Self-Learning Brain (`outreach/`, `apply/`, `hitl/`, `learning/`):**
   - **Track A (HR & Founder Cold Mailer):** Drafts or auto-sends hyper-tailored emails citing the exact social post URL, answers any post-specific questions using `qa_knowledge_base`, and attaches the tailored resume PDF generated by Stage 4 (`tailor`).
   - **Track B (Portal Form Auto-Applier):** Uses [Playwright MCP](https://github.com/microsoft/playwright-mcp) and a **5-Tier Zero-Token Cache** (`ats_selector_cache` + `qa_knowledge_base` + `pattern_rules`) to fill company career forms while minimizing LLM token usage by 80–95%.
   - **Shared Asynchronous Email HITL Loop:** Whenever **either** Track A (email drafter) or Track B (portal form filler) encounters a question outside the scope of `profile.json` and `qa_knowledge_base`, it parks the job, sends an email (`[ApplyPilot HITL #AP-XXXX]`) to the user via `scripts/gmail_oauth.py`, parses the user's inline email reply, permanently saves the new Q&A pair into `qa_knowledge_base`, and automatically resumes execution.

## Repository Directory & Thin-Hook Rules

**CRITICAL RULE FOR THE AI IDE:** Follow the **Thin-Hook Pattern** so upstream `git pull upstream main` from [ibarrajo/ApplyPilot](https://github.com/ibarrajo/ApplyPilot) never causes merge conflicts. Put 95% of new logic inside dedicated sub-packages under `src/applypilot/` and only add 1–5 line hooks to existing files (`cli.py`, `apply.py`, `track.py`).

## Lean 5-Server MCP Architecture & Search Cascade Configuration

To prevent prompt token bloat while maximizing omni-channel discovery and automation, ApplyPilot operates on a **Lean 5-Server MCP Architecture** coupled with a **2-Stage Search Engine Cascade**:

### 1. Two-Stage Search Engine Cascade
1. **Tier 1 — DuckDuckGo (`ddgs` / DuckDuckGo MCP) ($0 / Unlimited Quota)**:
   - Handles 100% of employer `/careers` URL resolution, company domain discovery, and initial tech-stack checks.
   - Saves paid API credits for deep scanning.
2. **Tier 2 — Brave Search MCP (Fresh Social Dorks)**:
   - Targeted specifically for fresh (past 24h: `freshness="pd"`) social hiring announcements:
     - `site:linkedin.com/posts ("we are hiring" OR "hiring") ("email" OR "@")`
     - `site:x.com ("we are hiring" OR "hiring a") ("email" OR "apply")`
   - High real-time recall on social networks where standard search indexes lag.
3. **Tier 3 — Firecrawl MCP (Custom Career Site Crawler)**:
   - For bespoke employer websites that do not use standard ATS platforms (Greenhouse, Lever, Ashby), `firecrawl_map` crawls `company.com/careers` and extracts all direct application links without launching a full Playwright session.

### 2. High-Value MCP Servers in the Pipeline

| MCP Server | Role in ApplyPilot | Strategic Benefit |
| :--- | :--- | :--- |
| **`applypilot-mcp`** | Core Engine | Controls local SQLite DB (`applypilot.db`), 5-Tier Zero-Token Cache, Email HITL loop, and Cold Mailer. |
| **`freehire`** / **`jobspipe`** | Job Feed Streamer | Streams 47,000+ active IT jobs, structured salaries, and ATS links (Workday, Greenhouse, Ashby, iCIMS). |
| **`playwright-mcp`** | Browser Automation | Navigates multi-step ATS portal forms, fills inputs, and uploads tailored resumes. |
| **`brave-search`** | Time-Bounded Dorking | Executes past-24h social hiring dorks across LinkedIn, X, and Threads. |
| **`firecrawl`** | Custom Career Site Mapper | Scrapes and maps non-standard corporate `/careers` pages into clean Markdown and URLs. |
| **`hunter`** *(Optional)* | Email Verifier | Verifies that extracted founder/recruiter emails are deliverable before dispatch, preventing hard bounces. |
| **`github-mcp`** *(Optional)* | Portfolio Evidence | Pulls verified technical proof from your GitHub repositories into cold outreach pitches. |
